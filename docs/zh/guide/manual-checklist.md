# 示例人工检查清单

示例通过公共入口引入库。运行 `npm run dev` 后逐项检查下面的内容，并且
`npm run build:demo` 也必须成功。

- [x] Markdown 渲染：演练场和 CommonMark 段落
- [x] 目录：导航和当前段落状态
- [x] 搜索：匹配高亮和自定义匹配渲染
- [x] 自定义标签：宿主组件映射和点击负载
- [x] HTML 安全：默认丢弃原始 HTML，通过 `htmlPlugin()` 启用并净化
- [x] 管线切换：官方、自定义和非法管线的回退
- [x] 无头用法：`useMarkdownDocument` 在没有预设组件时也能渲染
- [x] 插件扩展：源码变换、文档变换和诊断
- [x] 组件覆盖：标签、节点、区域和函数渲染器
- [x] 富节点：任务项和脚注
- [x] 高亮：默认 highlight.js 和独立高亮器
- [x] 数学：行内和块级公式
- [x] Mermaid：块预览/源码和可视化编辑器
- [x] 定制检查器：实时令牌、文案、主题、插槽、预设和组件覆盖

相同范围的自动化覆盖位于 `tests/dom` 和 `tests/node`。静态示例构建是导航和段落可达性
的发布检查。
